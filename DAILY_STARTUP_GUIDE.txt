================================================================================
METHOD 1: USING BATCH FILES (EASIEST - RECOMMENDED)
================================================================================

Step 1: Start XAMPP
-------------------
1. Open XAMPP Control Panel
2. Click "Start" for Apache
3. Click "Start" for MySQL
4. Wait until both show green "Running"

Step 2: Start Backend
--------------------
1. Go to your project folder:
   C:\Users\HP\OneDrive\Desktop\Soil_Analysis\
2. Double-click: START_BACKEND.bat
3. A black window opens and shows "Server is running on port 3000"
4. KEEP THIS WINDOW OPEN (minimize if needed)

Step 3: Start Frontend
---------------------
1. In the same project folder
2. Double-click: START_FRONTEND.bat
3. Another black window opens
4. KEEP THIS WINDOW OPEN TOO

Step 4: Open Application
------------------------
1. Double-click: OPEN_APPLICATION.bat
   OR
2. Open browser manually and go to:
   http://localhost:8080/index.html

DONE! Application is running! ✅

Total Time: ~1 minute

================================================================================
METHOD 2: MANUAL START (IF BATCH FILES DON'T WORK)
================================================================================

Step 1: Start XAMPP
-------------------
1. Open XAMPP Control Panel
2. Start Apache
3. Start MySQL

Step 2: Start Backend
--------------------
1. Press Windows Key + R
2. Type: powershell
3. Press Enter
4. Type: cd "C:\Users\HP\OneDrive\Desktop\Soil_Analysis\backend"
5. Press Enter
6. Type: npm start
7. Press Enter
8. Keep window open

Step 3: Start Frontend
---------------------
1. Press Windows Key + R (again)
2. Type: powershell
3. Press Enter
4. Type: cd "C:\Users\HP\OneDrive\Desktop\Soil_Analysis\frontend"
5. Press Enter
6. Type: npx http-server -p 8080
7. Press Enter
8. Keep window open

Step 4: Open Browser
-------------------
1. Open Chrome/Firefox/Edge
2. Go to: http://localhost:8080/index.html

-------------------

- Click "Stop" for Apache

Step 4: Shut Down Laptop
------------------------

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Backend won't start
Solution: Make sure XAMPP MySQL is running first

Problem: Frontend shows directory listing
Solution: Use http://localhost:8080/index.html (with /index.html)

Problem: "Port already in use"
Solution: Close all PowerShell windows and start fresh

Problem: Can't connect to database
Solution: Check XAMPP MySQL is running (green)

Problem: Login doesn't work
Solution: Check backend is running (port 3000)
