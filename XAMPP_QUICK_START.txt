🚀 SETUP STEPS (First Time Only)
================================================================================

STEP 1: START XAMPP
-------------------
1. Open XAMPP Control Panel
2. Click "Start" for Apache
3. Click "Start" for MySQL
4. Both should show green "Running"

STEP 2: CREATE DATABASE
-----------------------
1. Open browser: http://localhost/phpmyadmin
2. Click "New" in left sidebar
3. Database name: soil_analysis_db
4. Click "Create"

STEP 3: IMPORT DATABASE
-----------------------
1. Click on "soil_analysis_db" in left sidebar
2. Click "Import" tab
3. Click "Choose File"
4. Select: database/schema.sql
5. Click "Go" (wait for success)
6. Click "Import" again
7. Select: database/sample_data.sql
8. Click "Go" (wait for success)

STEP 4: INSTALL BACKEND DEPENDENCIES
------------------------------------
1. Open Command Prompt
2. Navigate to project:
   cd C:\path\to\your\project\backend
3. Run: npm install
4. Wait for installation to complete

STEP 5: CONFIGURE BACKEND
-------------------------
1. Open: backend/.env
2. Verify settings:
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=         (leave empty for XAMPP)
   DB_NAME=soil_analysis_db

================================================================================
▶️ RUNNING THE APPLICATION (Every Time)
================================================================================

METHOD 1: Using Batch Files (Easiest)
--------------------------------------
1. Double-click: START_BACKEND.bat
2. Double-click: START_FRONTEND.bat
3. Open browser: http://localhost:8080

METHOD 2: Manual Start
----------------------
Terminal 1 (Backend):
  cd backend
  npm start

Terminal 2 (Frontend):
  cd frontend
  npx http-server -p 8080

METHOD 3: Using XAMPP htdocs
----------------------------
1. Copy project to: C:\xampp\htdocs\
2. Only start backend:
   cd backend
   npm start
3. Open: http://localhost/soil-analysis-system/frontend/index.html

================================================================================
🔧 TROUBLESHOOTING
================================================================================

PROBLEM: Backend won't start
SOLUTION: 
  - Check XAMPP MySQL is running (green)
  - Verify .env file has correct settings
  - Run: npm install (in backend folder)

PROBLEM: Database connection error
SOLUTION:
  - Open phpMyAdmin: http://localhost/phpmyadmin
  - Check if soil_analysis_db exists
  - Check if tables exist (should be 6 tables)
  - Verify DB_PASSWORD in .env (usually empty)

PROBLEM: Frontend shows blank page
SOLUTION:
  - Press F12 in browser
  - Check Console for errors
  - Verify backend is running
  - Clear browser cache (Ctrl+Shift+Delete)

PROBLEM: Port 3000 already in use
SOLUTION:
  - Change PORT in backend/.env to 3001
  - Update API URLs in frontend JS files

PROBLEM: "Cannot find module"
SOLUTION:
  cd backend
  npm install
